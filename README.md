# Pixel Platformer (GDevelop)

Mario-style 2D platformer built with GDevelop — 1 level, 5 coins, patrolling
enemy, pits, goal flag. Touch controls for Android.

**Play/edit in the browser (no install):**

https://editor.gdevelop.io/?project=https://raw.githubusercontent.com/namphan1234560-ops/pixel-platformer-gdevelop/main/pixel-platformer.json

Art: Kenney Pixel Platformer pack (CC0, commercial-safe).
